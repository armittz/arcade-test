# arcade-test

A browser-based arcade featuring original games with colorful worlds, expressive characters, and increasingly challenging gameplay.

## Games

### 🍕 Pizza Delivery Drift
Take customer calls, memorize pizza designs, and recreate their orders. Carry each pizza to your car and navigate busy streets to deliver it hot and intact. Orders and delivery routes become harder as you progress.

### 🚀 Rocket Explorer
Pilot a rocket between planets while dodging asteroids, spaceships, and energy blasts. Explore each world, collect discoveries, and manage your fuel and shields.

## Play Online

Choose a game from the menu. Controls and instructions are available inside each game.

## Features

- Different gameplay styles, including driving, memory, and space exploration
- Progressive difficulty
- Animated characters and visual feedback
- Scores and replay challenges
- A shared arcade menu

## Technology

Built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
